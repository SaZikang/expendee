# Expendee 💸

A modern, mobile-first expense calculation and personal finance dashboard web application built with Python (Flask), SQLite, Tailwind CSS, Chart.js, and FontAwesome.

## ✨ Features

- **Mobile-First Design**: Optimized for mobile devices with an app-like bottom navigation bar.
- **Home Tab**:
  - Cashflow summary (Net Balance, Total Income, Total Expenses).
  - Quick-add Floating Action Button (FAB) for expenses.
  - Recent expense history with category icons on the left.
  - Quick modals to add income and custom categories.
- **Overview Tab**:
  - Interactive Pie Chart showing expense distribution by category.
  - Daily Cash Flow Chart comparing daily income vs. daily spending.
  - Month filtering for all analytics.
- **Budget Tab**:
  - Set overall monthly budgets and category-specific budgets with real-time progress bars.
- **Dark / Light Mode**: Seamless theme switching with persistent user preference.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/SaZikang/expendee.git
   cd expendee
   ```

2. Install dependencies:
   ```bash
   python3 -m pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python3 app.py
   ```

4. Open in your browser:
   ```
   http://127.0.0.1:5000
   ```
